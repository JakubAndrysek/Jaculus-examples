# LX-16D Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a tested TypeScript LX-16D bus-servo driver with a full high-level servo API and a runnable Jaculus demonstration.

**Architecture:** `src/lx16d.ts` contains a transport-independent byte codec, an `Lx16dBus` that serializes and validates UART transactions, and an `Lx16dServo` facade that maps domain operations to protocol commands. `src/index.ts` configures Jaculus UART itself, then uses the facade; the driver never calls `Serial.setup()` or `Serial.close()`.

**Tech Stack:** TypeScript ES2023, Jaculus `serial` module, Node test runner executed with `tsx`.

**Spec:** `docs/superpowers/specs/2026-09-02-lx16d-driver-design.md`

## Global Constraints

- The application owns UART configuration and lifecycle; the driver must not invoke `setup()` or `close()`.
- Use LX-16A-compatible frames: `55 55 ID LENGTH CMD payload checksum`; multi-byte values are little-endian.
- Use broadcast ID `0xfe` only through no-response send operations.
- Preserve error kind and request context in `Lx16dError`.
- Retain configurable `timeoutMs`, `retries`, `beforeTransmit`, and `beforeReceive` bus behavior.

```ts
class FakeSerial {
  readonly writes: Uint8Array[] = [];
  private readonly bytes: number[];
  constructor(reply: Uint8Array) { this.bytes = [...reply]; }
  write(data: Uint8Array) { this.writes.push(data); }
  flush() {}
  async get() { return Uint8Array.of(this.bytes.shift()!); }
}

test("writes a request and returns the matched response payload", async () => {
  const port = new FakeSerial(encodeFrame(1, Lx16dCommand.PositionRead, Uint8Array.of(0xf4, 1)));
  const bus = new Lx16dBus(port, { timeoutMs: 10, retries: 0 });
  assert.deepEqual([...await bus.transact(1, Lx16dCommand.PositionRead, 2)], [0xf4, 1]);
});
```

Add tests that reject a mismatched response ID, command, checksum, and a timeout; add one test proving two concurrent `transact` calls are written in call order.

- [ ] **Step 2: Run the bus tests and observe failure**

Run: `npm test -- test/lx16d.test.ts`

Expected: failure because `Lx16dBus` has not been implemented.

- [ ] **Step 3: Implement `Lx16dBus`**

Define `Lx16dSerial` structurally as `{ write(data): void; flush(): void; get(): Promise<Uint8Array> }` so Jaculus `serial.Serial` is assignable. Implement a promise queue around each operation. `send` runs direction hooks, writes, flushes, and does not read. `transact` rejects broadcast IDs, retries the configured number after framing/timeout errors, reads exact frame bytes with a `Promise.race` timeout, validates response ID/command/payload length, and returns payload. Call `beforeTransmit` before write and `beforeReceive` after flush before any receive.
